# Architecture Notes

When using `q1_final_plus`, keep it as a legacy controlled-replay protocol because its methods, numbers, and claims are not part of the confirmatory Selective Trust Quarantine v2.1 tables.
When closing Q1 reviewer dataset/tracker/baseline claims, run `scripts/audit_q1_practical_assets.py` and `scripts/check_review_closure_evidence.py` before editing the article because adapters, legacy outputs, and blockers must not be treated as validated results.
